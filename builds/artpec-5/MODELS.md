# AXIS ARTPEC-5 — geen build mogelijk

Deze map bevat bewust **geen** `.eap`.

## Modellen

| Model | Type | Artikelnummer |
|---|---|---|
| AXIS C1004-E | Network Cabinet Speaker (zwart / wit) | 0923-001, 0833-001 |
| AXIS C2005 | Network Ceiling Speaker | 0834-001 |
| AXIS C3003-E | Network Horn Speaker | 0767-001, 0767-008 |

## Waarom niet

ARTPEC-5 is een MIPS-chip. De ACAP Native SDK (waar deze app mee gebouwd wordt)
ondersteunt alleen armv7hf en aarch64. Alle drie de modellen zijn uitgefaseerd.
