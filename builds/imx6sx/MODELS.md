# NXP i.MX 6SoloX (armv7hf)

**Pakket:** `Spotify_Connect_1_0_0_armv7hf.eap`
**Gebouwd met:** ACAP Native SDK 12.1.0 (armv7hf)
**Vereist:** AXIS OS 12.1 of nieuwer

## Ondersteunde modellen

| Model | Type | Artikelnummer |
|---|---|---|
| AXIS C1210-E | Network Ceiling Speaker | 02324-001 |
| AXIS C1211-E | Network Ceiling Speaker | 02323-001 |
| AXIS C1510 | Network Mini Speaker | 02389-001 |
| AXIS C1511 | Network Mini Speaker | 02390-001 |
| AXIS C1610-VE | Network Sound Projector | 02380-001 |

## Let op

- Deze modellen draaien AXIS OS 12.11 LTS en kunnen naar AXIS OS 13. Axis meldt dat
  32-bit apparaten (zoals de i.MX 6SoloX) voor AXIS OS 13 een opnieuw gecompileerde
  ACAP nodig hebben. Deze build is **niet getest op AXIS OS 13**; blijf op 12.11 LTS
  tot er een SDK 13-build is.
- De C1210-E is het model waarop de app ontwikkeld en getest is.
